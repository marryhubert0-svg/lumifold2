# LUMIFOLD · 剪光

[Open the interactive presentation](https://marryhubert0-svg.github.io/lumifold2/?scene=archive)

A real-time Three.js presentation archive with all 17 body pages from the supplied LUMIFOLD deck. Arrow keys select a chapter or page; Enter opens the archive; OPEN SLIDE enters the full-page reader; Escape returns. Settings include reduced motion, rendering quality and fullscreen.

## Deployment

GitHub Pages: main branch, repository root. All model, font and slide paths use `/lumifold2/`. The production site is self-contained and does not need the author's local server.
